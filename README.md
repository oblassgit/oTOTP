# oTOTP

oTOTP is an Android application that provides a secure and user-friendly way to generate time-based one-time passwords (TOTP) for two-factor authentication (2FA). This project is built using Kotlin and Jetpack Compose.

## Features

- **Secure TOTP Generation**: Generate time-based one-time passwords for enhanced security.
- **Modern UI**: Built with Jetpack Compose for a clean and responsive user interface.
- **Lightweight**: Minimal dependencies and optimized performance.
- **Customizable**: Easily extendable to support additional features.
